LDM GUI.146 — WORKSPACE ONLY

Publish index.html, .nojekyll and static/ at your GitHub Pages repository root. The page opens the artwork workspace, without Desktop HOME, setup or machine controls. Default tabs: INBOX, VECTOR, TEXT, DRAW, ART LAB, 3D LAB. FOAM CUT is hidden by default. Once authenticated, the Desktop REMOTE ARTWORK ACCESS settings control availability.

Use the Pages URL with a trailing slash, for example https://mrbulp.github.io/LDM/ . This package uses directory-relative assets and works with either LDM or ldm repository names. Keep the static folder structure intact.

The collapsed LDM / ONLINE ARTWORK / CONNECT panel contains the Desktop HTTPS address and remote password. Theme, dark mode and language controls are in this panel. No cloud storage. Desktop and its artwork-only HTTPS tunnel must be online to submit. Existing Desktop GUI.146 remains unchanged. The tunnel must point only to 127.0.0.1:5430.
